# Brave Command - スマホ向けコマンドRPG MVP

縦画面スマホ向けの、フロントエンドだけで動作する1画面完結型ターン制コマンドRPGです。

## 遊び方

1. `index.html` をブラウザで開きます（ローカルサーバー推奨）。
2. ホームの「出撃する」からステージを選びます。
3. 行動中の味方ごとに「攻撃 / スキル / 防御 / 道具」を選択します。
4. 3 Waveの敵を全滅させるとEXPとゴールドを獲得し、次のステージが解放されます。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 実装内容

- 味方4人（戦士、魔法使い、盾役、支援拠点）
- 敵4種（スライム、骸骨、ゴースト、ドラゴン）
- 5ステージ × 各3 Wave
- 素早さ＋ランダム補正による行動順
- 通常攻撃、各キャラスキル、防御、5種の道具
- 物理・魔法ダメージ、属性弱点・耐性、回復、MP消費
- 毒、攻撃低下、防御低下、攻撃上昇、防御上昇、挑発などの状態効果
- 重み付き敵AIとドラゴンの行動予告・力溜めパターン
- 勝敗、報酬、レベルアップ、ステージ解放
- `localStorage` による進行・所持品・キャラ成長の保存
- 攻撃、被弾、回復、弱点、撃破の軽量アニメーション

## ファイル構成

- `index.html`: アプリのエントリーポイント
- `data.js`: キャラ、スキル、敵、ステージ、アイテム定義
- `game.js`: セーブ管理とUI非依存のバトル状態・計算・敵AI
- `app.js`: 画面遷移、DOM描画、入力処理
- `styles.css`: 縦画面向けレスポンシブUIと演出

## MVP上の簡略化

- グラフィックは外部画像ではなく絵文字とCSSで表現しています。
- 行動順はラウンドごとに再計算します。
- レベルアップ上昇値はキャラ共通の固定成長値です。
- 毒を付与するプレイヤースキルは将来追加用の処理のみで、初期スキルには含めていません。
- 聖・雷属性はデータ上の弱点として存在し、MVP初期パーティには対応スキルがありません。
